# Enclosure PCB revision tools

These scripts produce and check three **prototype** boards for the [bedroom alarm](../../enclosures/bedroom-alarm/pcb-revision/README.md). Do not run the generators over manual PCB edits: `create_boards.py` intentionally rebuilds the product revision from the preserved bench board. The source bench board is never overwritten.

Use Python 3, KiCad 10 with its Python `pcbnew` module, ngspice, Blender and optionally CadQuery, all free. On macOS the KiCad app bundles its CLI/Python; Linux distributions provide them separately. `KICAD_SHARE` can override the library directory, and `KICAD_CLI` the CLI path for exports/checks.

1. Run `python3 scripts/alarm/create_schematics.py`. Export each schematic as a `kicadxml` netlist into its `review/netlist.xml` using KiCad CLI.
2. Run `scripts/alarm/create_boards.py` with KiCad Python. This preserves reviewed non-UI copper and adds the connectors, button resistors and daughterboard footprints.
3. Compile `boards/esp32s3-devkit-5v/tools/grid_search.cpp` as a shared library (`clang++ -O2 -shared -fPIC`). Set `ALARM_GRID_LIBRARY` to its absolute path. Run `route_board.py boards/bedroom-alarm-main`, then repeat for `bedroom-alarm-controls` and `bedroom-alarm-front`, using KiCad Python. The router keeps In1.Cu reserved for ground and explicitly connects daughterboard ground pads. DRC is mandatory after routing.
4. Run `build_switch_model.py` using Python with CadQuery if the drawing-based EG1218 STEP is being regenerated. Run `finish_boards.py` with KiCad Python, then `check_boards.py`, `verify_interfaces.py`, and `verify_layout.py` (the latter requires KiCad Python). Run the repository's `make copper-check` and `make fab-drc` for each board, plus `make validate`.
5. Run `test_harness.py` with ngspice on PATH. Export the main-board SPICE netlist with `scripts/sim/export_kicad_spice.py`, then run `scripts/sim/run_sim.py --config boards/bedroom-alarm-main/sim.yml --report boards/bedroom-alarm-main/review/spice-report.md`. Sixteen damped cable corners are included in the normal CI simulation configuration; eight deliberately undamped cases serve as local negative controls.
6. Run `export_review.py`. Rebuild and verify the [Blender assembly](../../enclosures/bedroom-alarm/pcb-revision/README.md). A changed board/export/assembly invalidates the saved evidence; refresh the evidence together.

The [existing free physical-screening suite](../physics/README.md) was also rerun on fresh product-board copper, using the merged bench board as the comparison and the existing assumptions. The checked-in run uses its `ci` profile: coarse local extraction, circuit sensitivity cases and two nominal thermal grids. It does not claim new fine-mesh convergence, enclosure airflow, radiation or junction temperatures. Raw inputs, solver transcripts and matrices are archived under the main board's review directory.

The fixed custom footprints derive from the [E-Switch EG1218 drawing](https://configured-product-images.s3.amazonaws.com/2D/specs/EG1218.pdf) and the specified probe-pad geometry. Standard footprints/models come from KiCad and retain their embedded license notices. The inherited main-board models retain their existing provenance; new GH/switch/RGB models are package representations, not certification of an ordered assembly. The custom EG1218 STEP intentionally simplifies the switch's internal construction.

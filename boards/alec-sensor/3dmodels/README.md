# ALEC Sensor local 3D models

S1.1: all **88 electrical footprints** resolve to **19 project-local STEP files**. Four mounting holes and eight unpopulated test pads do not need body models. [The model audit](../review/3d-model-audit.json) lists every reference, model transform and SHA-256. The board GLB includes these populated components; this is file coverage, not a complete package-tolerance certification.

| Model group | Source and limits |
|---|---|
| Capacitors, resistors, fuse, SOT-23, TSSOP-14, RGB LED, ESP32-S3 | Installed KiCad 10 package library. [Upstream](https://gitlab.com/kicad/libraries/kicad-packages3D), [license and board-use exception](LICENSE-KiCad.txt). Passives are generic package envelopes, not exact MPN heights. |
| TPS63070RNM, XFL4020-152MEC | Existing repository assets from `libs/footprints/TPS63070.pretty`, retained from the reviewed converter cells. Package envelopes and lead alignment were previously inspected; original model authors are not identified. |
| HRO_TYPE-C-31-M-12 | Existing repository model from `libs/3d-models`, preserving the reviewed shell/tail datum transforms. Original model author is not identified. |
| TS-1187A-B-A-B | [Malouf's model](https://github.com/MaloufSleep/ME-ESP8266/blob/master/3D_Models/Button_Switch_SMD.3dShapes/TS-1187A-B-A-B.step), [MIT license](LICENSE-Malouf-MIT.txt). Selected 1.6 mm actuator-height variant at RESET, BOOT and exterior battery/pair button. RESET/BOOT are mounted on B.Cu; the exterior button remains on F.Cu. Verify purchased height/force before final membrane design. |
| JST_B2B-PH-SM4-TB_simplified | Existing drawing-based model: 7.95 × 5 × 6.6 mm body, 2 mm pitch. [JST PH drawing](https://www.jst-mfg.com/product/pdf/eng/ePH.pdf). Internal ribs/latch are simplified; mating plug and bent harness remain enclosure allocations. |
| RV-3028-C7_simplified | Existing drawing-based model: 1.5 × 3.2 × 0.8 mm envelope. [Micro Crystal drawing](https://www.microcrystal.com/fileadmin/Media/Products/RTC/Datasheet/RV-3028-C7.pdf). Lid/seal details simplified. |
| SW_CK_1101M2S3CQE2 | New custom envelope from the [C&K/Littelfuse 1000 drawing](https://www.littelfuse.com/assetdocs/littelfuse-c-k-slide-1000-series-datasheet?assetguid=68a2b41e-19a4-4cf4-821b-aca78a430f00), including body, actuator and through-hole terminals. Mounted on B.Cu; exposed terminal tips are included on the front side. |
| Samtec_SSW-105-01-F-S | New custom envelope from the [Samtec SSW drawing](https://suddendocs.samtec.com/prints/ssw-1xx-xx-xxx-x-xx-xxx-xx-mkt.pdf). Body 13.21 × 2.41 × 8.51 mm, five positions at 2.54 mm, 2.64 mm solder tails. Internal contacts simplified. |

`../tools/build_part_models.py` regenerates the new switch and socket using free CadQuery 2.8.0. Existing simplified models can be regenerated by the corresponding source-board tools; their provenance is retained here. Color and cosmetic detail do not certify fit. Final capacitor heights, connector mating/retention, lead trimming, solder fillets and enclosure tolerances need assembly samples.
